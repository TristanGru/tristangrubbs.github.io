Personal portfolio site for Tristan Grubbs (UVA CS, May 2026). Built to communicate the arc: UVA CS → Government tech (NIWC) → MBA → AI/Digital Strategy.

MBA admissions committees, alumni networks, and anyone evaluating a literary-technical profile targeting MBB consulting and AI/digital strategy roles.
